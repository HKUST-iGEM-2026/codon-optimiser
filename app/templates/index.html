What these four numbers mean

Some codons get used far more than their synonyms. Two different things cause that. Mutation: this genome is {{ org.organism.genomic_gc_percent | round(1) }}% GC, and at the third letter of a codon, where a change usually leaves the protein alone, it falls to {{ (gate.s_index.genomic_gc3 * 100) | round(1) }}%. A and T build up there on their own. Selection: the cell stocks some tRNAs more heavily than others, and codons matched to a plentiful tRNA are read faster, so genes needed in bulk shift toward them. Only the second is worth copying. Under mutation alone, "use the most common codon" would just mean "add more A and T". These four checks test which one is at work.

Ribosomal CAI rank
CAI scores a gene on how often it picks the codons this organism's hardest-working genes prefer. 1.0 is the maximum. Ribosomal proteins are built in huge numbers, so if CAI tracks workload they should score near the top. Across all {{ gate.ribosomal_cai_rank.n_ranked_genes }} genes, the {{ gate.ribosomal_cai_rank.n_ribosomal }} ribosomal ones sit at a median of {{ gate.ribosomal_cai_rank.median_rank }}, the top {{ gate.ribosomal_cai_rank.median_percentile }}%. Two caveats: the scoring table came from those same genes, so the check cannot fail badly, and everything depends on the table. Score the same genes using codon counts from the whole genome and they drop to {{ gate.ribosomal_cai_rank.under_genome_weights.median_rank }}.
S index (sscu)
Four amino acids (Tyr, Asn, Ile, Phe) use two codons that differ only in a third letter of C or T. Mutation pushes that letter toward T. The tRNA supply favours C. The two forces pull opposite ways, so they can be told apart. Mutation alone predicts C about {{ (gate.s_index.genomic_gc3 * 100) | round(1) }}% of the time, which is what the genome does. The hardest-working genes use C 40 to 51% of the time. The index measures that gap on a log scale: {{ gate.s_index.value }}. Above 0.3 counts as selection, and mutation cannot lift it above zero, because zero is what mutation predicts.
eCAI 95th pct
A CAI of {{ gate.ecai.observed_reference_cai }} sounds high, but high next to what? Where the favoured codons end in A or T, a random A/T-rich stretch scores well by accident. So a baseline is built: {{ gate.ecai.replicates }} imitation gene sets, using the real proteins but choosing codons from base composition alone, with no preference between synonyms. They average {{ gate.ecai.null_mean }}, and 95% stay under {{ gate.ecai.value }}. The real genes score {{ gate.ecai.observed_reference_cai }}, above that line, so the pattern is too strong to be a side effect of composition.
Ribosomal in self-consistent set
The first check was told which genes work hardest. This one is told nothing and has to find them. It scores every gene using codon counts from the whole genome, keeps the top {{ gate.overlap.self_consistent_set_size }}, rebuilds the counts from those, and scores again, until the group settles after {{ gate.overlap.iterations }} rounds. If translation drove codon choice, that group would fill with ribosomal genes. It holds {{ gate.overlap.shared }} of the {{ gate.overlap.ribosomal_set_size }}. This check fails. The starting counts are the problem: taken from the whole genome, they reward A/T-richness, so round one picks the most A/T-heavy genes and later rounds commit harder to them. The same procedure run on E. coli finds 33 of that organism's 45 ribosomal genes, 73% against {{ (gate.overlap.fraction_of_ribosomal_set * 100) | round(1) }}% here. E. coli is near 50% GC, so mutation there does not fight the tRNA signal. The method works; this genome is the wrong place to start it, which is why the reference genes here are taken from the genome's annotation instead.

The rule was set before the numbers were known: S index above 0.3 and eCAI passing means maximise by default, otherwise harmonise. Only those two ignore base composition, so only those two vote. Both pass, so the default is {{ org.default_mode }}.

How to use this
  1. Paste a protein (MSKIYA…) or a coding sequence (ATGAGC…). Pure ACGT/U with a length divisible by 3 is read as a CDS, and its own CAI is reported beside the new one. The cap is {{ limits.input_cap_nt }} nt of output.
  2. Pick a mode. Maximise gives every amino acid the reference set's favourite codon. Harmonise reproduces the genome's own codon distribution, rare codons included. The default is {{ org.default_mode }}, decided by the gate above.
  3. List the motifs your cloning strategy forbids, such as GAATTC, GGATCC, GGTCTC. IUPAC codes work and both strands are checked. A returned sequence never contains one. Maximising CAI creates these sites, since the best codons spell GAA·TTC for every EF in your protein.
  4. Leave the seed at {{ default_seed }}. The same input and seed give the same output. Change it to redraw a harmonisation, or to retry a solver gave up refusal.
  5. Tick Create permalink for a shareable link, then press Optimise. Only the request is stored, never the sequence.

Reading the result

CAI
Geometric mean of per-codon relative adaptiveness. 1.0 is the reference set's favourite codon everywhere. Met, Trp and stops have no synonym and are not scored.
GC
The global band is hard. The 50nt window has a hard ceiling and a flagged-only floor, since a floor would forbid sequence this organism's own genes contain.
Changed codons
Counted against your CDS, or against the mode's baseline for protein input. Counted again after codon 12, where the weights were trimmed.
5′ ΔG
Folding energy of the first 40 nt. Near zero means open, which is what initiation wants. A large negative number is worse, not better.
Codon track
Colour by adaptiveness or by what moved each codon. Hover a codon for its weight, the rule that moved it, and the local ΔG that choice cost.
Flags vs warnings
Flags are soft liabilities left in the sequence. Warnings describe the run. A hard rule is never left violated: the request is refused with coordinates and no sequence.
Manifest
Every constant the run used, carried into Copy and Export FASTA so a result can be reproduced elsewhere.
