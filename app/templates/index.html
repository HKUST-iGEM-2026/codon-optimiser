How to use this
  1. Paste a protein (MSKIYA…) or a coding sequence (ATGAGC…). Pure ACGT/U whose length divides by 3 is read as a CDS and its own CAI is reported next to the new one; anything else is read as protein. The cap is {{ limits.input_cap_nt }} nt of output.
  2. Pick a mode. Maximise gives every amino acid the reference set's favourite codon (CAI → 1.0). Harmonise reproduces the genome's own codon distribution, rare codons included. The default is {{ 'maximise' if org.default_mode == 'maximise' else 'harmonise' }} because the gate above {{ 'passes' if org.default_mode == 'maximise' else 'fails' }}.
  3. List the motifs your cloning strategy forbids — restriction or Type IIS sites such as GAATTC, GGATCC, GGTCTC. IUPAC codes are accepted and both strands are checked. These are hard: a returned sequence never contains one. Maximising CAI creates such sites (best codons spell GAA·TTC for every EF in your protein), so this field earns its keep.
  4. Leave the seed at {{ default_seed }}. Same input and seed always give byte-identical output; change it only to redraw a harmonisation, or to retry a solver gave up refusal.
  5. Tick Create permalink if you want a shareable link, then press Optimise. Only the request is stored, never the sequence: the link recomputes.

Reading the result

CAI
geometric mean of per-codon relative adaptiveness; 1.0 is the reference set's favourite codon everywhere. Met, Trp and stops have no synonym and are not scored.
GC
global band is a hard constraint. The 50nt window has a hard ceiling and a flagged-only floor: a floor would forbid sequence this organism's own genes contain.
Changed codons
against your CDS, or against the mode's own baseline for protein input. Counted again after codon 12, because the weights were built on genes trimmed there.
5′ ΔG
folding energy of the first 40 nt. Near zero means open, which is what translation initiation wants. Do not read a large negative number as "stable, therefore good".
Codon track
colour by adaptiveness or by what moved each codon; hover one for its weight, the exact rule that moved it, and the local ΔG that choice cost.
Flags vs warnings
flags are liabilities deliberately left in the sequence (soft rules); warnings are things about the run. A hard rule is never left violated — the request is refused with coordinates instead, and no sequence comes back.
Manifest
every constant the run used, carried into Copy and Export FASTA. It is what makes a result reproducible somewhere else.
