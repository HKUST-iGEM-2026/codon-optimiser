What these four numbers mean

Codon bias has two causes that look identical in the counts. Mutation: this genome is {{ org.organism.genomic_gc_percent | round(1) }}% GC and its third codon positions only {{ (gate.s_index.genomic_gc3 * 100) | round(1) }}%, so A/T-ending codons accumulate on their own. Selection: codons read by abundant tRNAs translate faster, so heavily expressed genes shift toward them. Only selection makes codon adaptation worth maximising, so these four checks test for it.

Ribosomal CAI rank
Do genes known to be heavily expressed score well? A cell runs tens of thousands of ribosomes, so its {{ gate.ribosomal_cai_rank.n_ribosomal }} ribosomal protein genes are among the busiest. Ranked against all {{ gate.ribosomal_cai_rank.n_ranked_genes }} genes, their median position is {{ gate.ribosomal_cai_rank.median_rank }}, the top {{ gate.ribosomal_cai_rank.median_percentile }}%. Partly circular, since the weights come from those genes. Scored against genome-wide frequencies instead they fall to rank {{ gate.ribosomal_cai_rank.under_genome_weights.median_rank }} ({{ gate.ribosomal_cai_rank.under_genome_weights.median_percentile }}th pct), which shows how much the choice of weights decides.
S index (sscu)
Do the busy genes use codons mutation cannot explain? Measured on the four two-codon families ending in C or T (Tyr, Asn, Ile, Phe), where selection favours C and drift favours T. Mutation predicts a C-ending share near GC3, {{ (gate.s_index.genomic_gc3 * 100) | round(1) }}%. The reference genes use 40 to 51%. The index is that excess in log odds: {{ gate.s_index.value }}, against sscu's threshold of 0.3. Drift cannot produce a positive value.
eCAI 95th pct
Is a CAI of {{ gate.ecai.observed_reference_cai }} high, or does everything score that well here? {{ gate.ecai.replicates }} fake gene sets keep the real amino acid sequences but pick codons from base composition alone. They average {{ gate.ecai.null_mean }} and 95% fall below {{ gate.ecai.value }}. The reference set scores {{ gate.ecai.observed_reference_cai }}, {{ 'clearing' if gate.ecai.passes else 'missing' }} the bar at the 5% level. Composition-matched noise already earns {{ gate.ecai.null_mean }} here, so the raw CAI means little without this baseline.
Ribosomal in self-consistent set
Can the busy genes be found without the answer key? From genome-wide weights, take the top {{ gate.overlap.self_consistent_set_size }} genes, rebuild the weights from those, re-rank, and repeat until the set stops changing ({{ gate.overlap.iterations }} rounds). It recovered {{ gate.overlap.shared }} of the {{ gate.overlap.ribosomal_set_size }} ribosomal genes, {{ (gate.overlap.fraction_of_ribosomal_set * 100) | round(1) }}%. This check fails. Genome-wide weights reward A/T-richness, so the first pass picks A/T-extreme genes and each round reinforces that. The same code recovers 33 of 45 on E. coli, so the reference set here has to come from annotation, not iteration.

The rule was fixed before the numbers: S index above 0.3 and eCAI passing gives a maximise default, otherwise harmonise. Only those two ignore composition, so only they vote. Both pass, so the default is {{ org.default_mode }}.

How to use this
  1. Paste a protein (MSKIYA…) or a coding sequence (ATGAGC…). Pure ACGT/U with a length divisible by 3 is read as a CDS, and its own CAI is reported beside the new one. The cap is {{ limits.input_cap_nt }} nt of output.
  2. Pick a mode. Maximise gives every amino acid the reference set's favourite codon. Harmonise reproduces the genome's own codon distribution, rare codons included. The default is {{ org.default_mode }}, decided by the gate above.
  3. List the motifs your cloning strategy forbids, such as GAATTC, GGATCC, GGTCTC. IUPAC codes work and both strands are checked. A returned sequence never contains one. Maximising CAI creates these sites, since the best codons spell GAA·TTC for every EF in your protein.
  4. Leave the seed at {{ default_seed }}. The same input and seed give the same output. Change it to redraw a harmonisation, or to retry a solver gave up refusal.
  5. Tick Create permalink for a shareable link, then press Optimise. Only the request is stored, never the sequence.

Reading the result

CAI
Geometric mean of per-codon relative adaptiveness. 1.0 is the reference set's favourite codon everywhere. Met, Trp and stops have no synonym and are not scored.
GC
The global band is hard. The 50nt window has a hard ceiling and a flagged-only floor, since a floor would forbid sequence this organism's own genes contain.
Changed codons
Counted against your CDS, or against the mode's baseline for protein input. Counted again after codon 12, where the weights were trimmed.
5′ ΔG
Folding energy of the first 40 nt. Near zero means open, which is what initiation wants. A large negative number is worse, not better.
Codon track
Colour by adaptiveness or by what moved each codon. Hover a codon for its weight, the rule that moved it, and the local ΔG that choice cost.
Flags vs warnings
Flags are soft liabilities left in the sequence. Warnings describe the run. A hard rule is never left violated: the request is refused with coordinates and no sequence.
Manifest
Every constant the run used, carried into Copy and Export FASTA so a result can be reproduced elsewhere.
